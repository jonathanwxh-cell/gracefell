# GRACEFELL v2.27.6 release record — break the crown

Date: 2026-07-29

Implementation, verification, and release: Codex (GPT-5 / Codex Desktop)

Package: `gracefell@2.27.6`

Publication state: accepted production checkpoint

## Outcome

Sunder and Execute retain their established combat authority but now read as
different impacts on Malakar himself. Sunder briefly compresses the king,
splays his halo, and fractures the crown in gold. Execute drives a stronger
pose, wider crown burst, and narrow spirit cleave. The central feedback lane
remains the one technique-name authority, duplicate boss-local technique words
are removed, numeric damage remains beside Malakar, and desktop readiness names
the authored `K` key while touch keeps `HVY`.

The reactions are presentation-only. Damage, poise, stamina, Resolve, hitstop,
timings, stagger and phase authority, difficulty, scoring, save-v7, audio,
assets, touch targets, boss position, collision, AI, and hostile telegraph
colors are unchanged.

## Implementation boundary

- `Boss.techniqueImpact` enters the existing read-only render snapshot.
- Canvas and opt-in Three rendering consume the same bounded impact strength
  for pose compression and halo spread.
- Sunder uses deterministic gold fracture paths; Execute adds a bounded spirit
  cleave and stronger crown burst.
- The state decays to `null`, resets on a new fight, and never enters gameplay
  decisions or collision authority.
- Central `SUNDER` / `EXECUTE` copy is retained once; duplicate local words are
  removed while damage numbers remain.
- Desktop Sunder/Execute readiness says `TAP K`; touch says `TAP HVY`.

### Harness evidence retained

The first public v2.27 capture timed out after its full-page ready screenshot
took longer than Sunder's real 600 ms route window. The QA lane now stops the
simulation only while recording that evidence frame and resumes before sending
the genuine HVY touch. It does not widen, replace, or bypass the player-owned
timer.

An amended complete public run then sampled two unrelated legacy timing edges:
phase-three weather easing at 0.985227 immediately before its terminal sample,
and a 51.2 ms first audio gesture whose native `AudioContext` construction took
49 ms while graph work remained 2.1 ms. This release changes neither system.
No threshold was weakened; the clean public main rerun passed, followed by
fresh zero-error focused, performance, and visual gates.

This non-runtime acceptance checkpoint changes QA and tracked evidence but no
shipped runtime file. The annotated `v2.27.6` tag and GitHub release target its
exact merge so code, deployment evidence, and future-agent handoff remain one
durable release.

## Known limits

- Headless touch validates geometry, screenshots, state, and event ownership;
  subjective haptics, thumb latency, phone-speaker mix, and iOS Safari still
  require a physical device.
- The existing Browserslist-age and optional Three.js large-chunk warnings are
  unchanged.
- Dependencies and save schema are unchanged.
