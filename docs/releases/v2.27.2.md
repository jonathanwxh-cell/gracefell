## Outcome

v2.27.2 fixes the combo-clarity and input-reliability findings reproduced in a
focused v2.27.1 gameplay review:

1. a poise-breaking second light could leave Sunder ahead of the earned
   stagger Execute;
2. the 260 ms generic input buffer expired inside the player's 320 ms wound
   recovery;
3. the connected/uninterrupted Sunder requirement and route resets were not
   explained at the moment of play;
4. the combo lane and unchanged HVY label did not make the next action clear;
5. returning players lacked an in-battle technique reference.

The patch corrects priority and presentation without widening the proven
600 ms route window or changing damage, stamina, Resolve, boss patterns,
difficulty, scores, save schema v7, audio, weather, runtime assets, touch
targets, or persistent settings.

## Implementation

### Execute outranks the mixed route

`Player.update()` now classifies a buffered route-heavy against current boss
state. When Malakar is staggered, the command enters ordinary HVY and reaches
the established one-per-stagger Execute branch. Otherwise it enters Sunder.
ROLL remains the first state-transition check. A Sunder queued before the
second contact therefore cannot steal an Execute created by that contact.

### One recovery command survives a wound

The player owns one transient `recoveryAction` while in the 320 ms stagger
state. ATK, HVY, FLASK, or ROLL may occupy it; a later ROLL replaces an earlier
choice. Recovery re-buffers that one action into the normal lane, preserving
existing stamina checks and action priorities without making all neutral input
stickier.

### Contact-authoritative feedback

The transient lane now distinguishes:

- `1 HIT · LAND NEXT ATK`;
- `SUNDER READY · TAP HVY`;
- `EXECUTE READY · TAP HVY`;
- `RECOVERING · <ACTION> QUEUED`;
- `CHAIN LOST · MISS/HIT/ROLL/TOO SLOW/NO STAMINA`.

The existing touch HVY button becomes `SUNDER` or `EXECUTE` only while that
action is authoritative. The Sunder cue retires with an 80 ms presentation
margin before the simulation deadline. Pause lists the Light Finisher, Sunder,
and Gracebreak recipes; the semantic combat panel includes the queued recovery
action; Combat tips name the connected/uninterrupted requirement and reset
causes.

  whiff, restores stamina only on contact, and cannot bypass FORSAKEN.

## Known limits

- Browser automation certifies layout, controls, state, persistence, asset
  loading, and audio routing; it cannot certify subjective audio quality,
  haptic feel, hand fatigue, or a natural human FORSAKEN clear.
- Real iOS Safari URL-bar/dvh behavior and vibration remain outside headless
  Chromium.
- The optional query-gated Three.js Malakar proof remains non-default and its
  existing large-chunk warning remains.
- Browserslist data remains seven months old. Neither warning is introduced by
  this release.

## Rollback

Revert the v2.27.2 runtime merge, run the complete gate, deploy that reviewed
revert, restart `gracefell.service`, and rerun public QA. Save schema v7 and
all persisted values are unchanged, so rollback needs no data migration.
