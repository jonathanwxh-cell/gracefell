## Outcome

At full Resolve, the mobile heavy circle visibly changed to `BREAK`, but one
tap still produced an ordinary uncharged heavy. The special required the player
to keep a finger on the circle through the full charge even though the
contextual button presented BREAK as the tap action.

v2.27.3 makes one deliberate touch tap own that visible command. The tap
latches the existing 0.5-second charged-heavy sequence and releases exactly one
Gracebreak when full. It does not create a new verb, skip the charge, or change
combat values.

The input reached combat correctly; the mismatch was between the contextual

## Implementation

`Player.gracebreakTouchLatch` is captured only when an ordinary touch heavy
starts at full Resolve and Malakar is not staggered. While set, it satisfies
the existing hold predicate until `Player.HEAVY_MAX_CHARGE` reaches its
unchanged 0.5-second maximum. The next simulation frame takes the existing
release path.

The latch clears on release, heavy exit, and player damage. It cannot steal:

- connected-hit Sunder, which resolves before ordinary heavy;
- stagger Execute, which disables the latch and retains its established
  priority;
- keyboard or right-mouse partial heavies, which still require manual hold and
  preserve Resolve when released early.

Touch instructions and the touch pause recipe now say
`FULL RESOLVE · TAP BREAK · GRACEBREAK`. Desktop continues to say
`HOLD K/HVY`.

### Acceptance-discovered charge reservation hardening

A later complete replay found a stopped charge cue still occupying one
critical voice slot at the lifecycle assertion. Cue ownership was already
false; only allocation release awaited delayed physical node cleanup.

Sustained voices now separate an idempotent `releaseReservation()` from
idempotent node `cleanup()`. Stop releases the scarce voice slot synchronously
after scheduling the unchanged 90 ms fade. Nodes remain connected for that
fade and disconnect through `onended` or the existing 160 ms wall-clock
backstop. This changes no cue, gain, fade, asset, node family, or gameplay
event, but a logically stopped charge can no longer block later combat sounds.

## Unchanged combat contract

- Charge duration: 0.5 seconds.
- Gracebreak damage: 72.
- Total poise pressure: 112.
- Stamina cost: 26, with the existing 20-stamina contact restoration.
- Full Resolve is spent once on release, including a whiff.
- Execute remains one per poise break and outranks Gracebreak.
- Sunder still requires two connected uninterrupted light hits within 600 ms.
- FORSAKEN remains IRONBOUND.
- Difficulty, boss patterns, scores, save schema v7, audio graph/assets, touch
  geometry, weather, and rendering remain unchanged.
