# GRACEFELL v2.21.1 release record

Date: 2026-07-25
Owner: @jonathanwxh-cell
Implementation and verification: Codex

Status: merged, deployed, and publicly verified

## Outcome

The title screen no longer distorts on short phone browser viewports when saved
victory information is present. The result summary, start prompt, touch guidance,
Journey/Oath summary, five-row settings plate, settings instruction, and thematic
footer now occupy one measured vertical layout without overlap.

This is a presentation-only hotfix. Difficulty, boss behavior, combat timing,
weather, music, sound effects, scoring, persistence, accessibility semantics, and
touch hit targets are unchanged.

## Root cause and repair

The five settings rows already shared one geometry function for drawing and hit
testing, but the surrounding title copy used independent percentages of viewport
height. On a short iPhone browser viewport those percentages converged: the touch
guidance and Journey summary crossed into the first settings row, while the
settings instruction crossed the footer.

The repair:

- anchors compact title copy to the measured top of the settings plate;
- preserves explicit spacing between saved results, prompt, controls, summary,
  and menu;
- shifts the whole settings plate upward only when a short viewport needs bottom
  clearance;
- keeps every rendered settings row and its tap target on the same geometry;
- adds true-touch assertions for title, menu, instruction, and footer separation.

## Performance review

Three independent read-only performance personas reviewed the preceding public
build before release:

- desktop rendering remained inside a 16.7 ms frame budget, including synthetic
  dense phase-three scenes at 1920x1080 (`p95 3.3 ms`, `max 7.8 ms`);
- weather-only phase cost remained approximately `0.5 ms` at p95;
- six retry/victory lifecycle cycles left DOM nodes and retained music nodes flat
  (`164 -> 164` and `24 -> 24`) with no confirmed leak;
- a synthetic 6x-CPU mobile stress scene reached `24.8 ms` p95 but never crossed
  33 ms. It remains a physical-low-end-device watch item, not a confirmed
  production regression.

The menu repair adds only arithmetic layout calculations and no persistent render
pass, asset, listener, node, particle, or network request.
