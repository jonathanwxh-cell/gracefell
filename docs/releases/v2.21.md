Date: 2026-07-25
Owner: @jonathanwxh-cell
Implementation and verification: Codex (GPT-5 / Codex Desktop)

## Scope

This release resolves the six remaining viable enhancement issues:

- #57 buffered post-roll slash without iframe cancellation;
- #58 rear-arc FLANK reward (1.25x damage, 1.5x poise; no windup/stagger stacking);
- #60 explicit post-score REMAIN and exactly one-step ASCEND actions;
- #62 run-local damage mix, phase splits, recent wounds, and grade guidance;
- #63 local 1080x1350 victory PNG with Web Share/file-download fallback;
- #64 mirrored joystick/action layout persisted in save schema v7.

It also replaces vague Oath summaries with the already-active damage, chain,
flask, poise, and no-stagger rules; separates combat callout lanes; clears stale
damage text at terminal transitions; and fixes an AudioParam automation overlap
found by the expanded gate.

## Safety and performance boundaries

- Roll slash starts only after the complete dodge and costs 10 stamina.
- FLANK is disabled during windup and stagger, so it cannot multiply EXECUTE.
- Chronicle data is run-local and presentation-only.
- Ascension is unavailable until the existing 4.5-second victory hold ends.
- Share rendering is one user-triggered offscreen canvas; no runtime image,
  network request, third-party service, or persistent render pass was added.
- Mirroring changes the shared geometry and acquisition rules, not hitbox size.
- Difficulty values, grading, weather, music masters, and runtime assets are unchanged.
