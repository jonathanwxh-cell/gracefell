## What changed

Two original Blender-authored character models replace the simple Canvas bodies
on hardware-accelerated browsers. Kite-Veil has silver armor, a teal divided
mantle, sallet, vambraces, articulated gauntlets, greaves and a longsword.
Malakar has blackened steel, gilt ribs, a broken nine-tine crown, cloth mantle,
pauldrons, two blades, and his existing nine-fragment phase-reactive halo.
Anatomical nodes retain limb, head, cloth and weapon pivots. Idle/movement,
attacks, charge, flask, roll, stagger, technique impact and phase states drive
their presentation directly from the existing combat state.

The physical material pass uses an environment reflection map, warm key light,
cool rim light, filmic tone mapping, forged-metal color/roughness variation,
and emissive visor/chest accents. Cloth deforms from immutable rest positions
using the game's paused presentation clock. Reduced-motion preferences scale
the cosmetic motion.

The arena is new Blender geometry: beveled radial ashlar, bronze inlays, a
central rosette, clustered pillars, broken gothic arch ribs, rubble and candles.
CC0 photographic stone supplies diffuse, displacement and roughness. Cycles
bakes the lighting and indirect shadows into a 2048×2048 WebP; runtime uses the
existing adaptive cached floor. **The arena is a baked image; the two characters
are live 3D models.** This preserves the established 2.5D camera and hit geometry.

## Rebuild

Run `scripts/art/build_reliquary.ps1 -BlenderExe <path-to-blender.exe>`.
The script fetches three checksum-locked 2K stone source maps, generates and
renders in Blender 4.5 LTS, exports GLB, runs pinned glTF Transform 4.4.1, then
validates budgets. `-SkipBlender` only reoptimizes/validates existing raw exports.
The source `.blend` files retain the mesh hierarchy; the arena source packs its
CC0 textures. Blender was run in a separate background process with factory
startup, so no existing editor scene was replaced.

The portable Blender tool copy lives in ignored `.artifacts/tools` and is not
shipped. The two raw GLBs and three `.blend` files are source assets, not runtime
downloads. No Git LFS requirement is introduced; the largest source is 8.2 MB.

## Runtime behavior

One detached WebGL context composites both characters into the existing visible
canvas: 640px character surface on desktop, 384px on touch. There is no second
simulation loop, React animation state, independent animation clock or root
motion. World position, collision circles, telegraph geometry, damage, poise,
stamina, input timing, difficulty, saves, scoring and audio are unchanged.

Networking starts after the existing 120ms post-gesture delay. Both models must
be ready before promotion at title/intro/pause; a late load waits for a safe
boundary. A failed model releases the GPU context. Context loss restores the
Canvas bodies; restored environment reflections are rebuilt before reactivation.
Known software rasterizers use Classic characters automatically. The new stone
arena can still display without WebGL. Explicit old visual queries and the title
GRAPHICS toggle remain available.
