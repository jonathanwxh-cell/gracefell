# GRACEFELL v2.22.1 release record

Date: 2026-07-26
Owner: @jonathanwxh-cell
Implementation and verification: Codex

Status: merged, deployed, and publicly verified

## Outcome

The reported iPhone combat HUD collision is repaired. HP, stamina, and flasks
now keep their own top status lane, while MENU, MIX, PAUSE, and SOUND form one
consistent 44px utility rail beneath them on compact screens.

This is a presentation-only hotfix. Combat, boss behavior, difficulty, input,
scoring, persistence, save schema v7, weather, music, and sound effects are
unchanged.

## Root cause

The player HUD and SOUND control are Canvas content, while MENU, MIX, and PAUSE
are DOM controls. Existing acceptance proved each control was visible and
fingertip-sized but did not compare the two layers.

At the reported 390×844 viewport:

| Element | Before |
| --- | --- |
| Player resource HUD | `x=16..210`, `y=16..76` |
| MIX | `x=146..210`, `y=12..56` |
| Result | MIX overlapped the right 64px of the HP bar |

## Repair

- `playerHudRect()` centralizes the protected Canvas resource geometry.
- Compact utilities share `y=82`, below the HUD's `y=76` boundary.
- MENU, MIX, PAUSE, and SOUND use 44px-high touch targets.
- Compact teaching and combo feedback move below the utility rail.
- QA now compares every utility against the protected HUD and every other
  utility, in addition to viewport and fingertip checks.
